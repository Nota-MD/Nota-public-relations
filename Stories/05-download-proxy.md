# 5 · 下载代理

这应该算是中国大陆地区用户特供吧。 众所周知，在中国大陆地区，GitHub等虽然没有被加入网络防火墙黑名单，但是下载非常慢，具体原因未知，可能是限流或服务器不在国内。 所以中国大陆地区的程序员平时要么用VPN，要么用代理站。

但是VPN有两个问题，其一违反当地法律，其二下载可能产生一定费用。

而使用公共代理站诸如<https://ghproxylist.com/>等即可以免费高效合法加速。但是这仅限于下载，不能提交，因为不安全。所以也无法全局代理。

所以，我往Nota中加入了下载代理功能，诸如使用： 

```
github.com/ => ghproxylist.com/https://github.com/
```

这样的替换规则，可以将Nota下载软件包的地址替换。
