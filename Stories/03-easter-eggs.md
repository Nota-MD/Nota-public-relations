# 3 · 在细节中藏彩蛋

最后更新：2026-11-15

这里有个小小的互动环节。

在不看答案的情况下，您可以想想如何进入开发者模式。

以及，E2E 用来测试导出大文档的是哪一份文档。

<details>
  <summary>点击查看答案</summary>

  **答案：**

  <ol>
    <li>打开「关于」，在 2.5 秒内连续点击版本号五次；</li>
    <li>Eric S. Raymond 所著的
      <em>The Cathedral &amp; the Bazaar: Musings on Linux and Open Source by an Accidental Revolutionary</em>，
      常被视为开源运动的重要文献。
    </li>
  </ol>
</details>

嗯，彩蛋不应该是外露的。大张旗鼓地向用户展示自己的趣味，用户反而会觉得不正经；把它藏在细节里，某次意外触发带来的惊喜，才是软件给人情绪价值的好办法。
